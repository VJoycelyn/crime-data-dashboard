# Project sources

Space Grotesk by Florian Karsten Typefaces is the selected open-source dashboard typography. Source: https://fonts.floriankarsten.com/space-grotesk. The font is served via Google Fonts with a system-font fallback.

The proposed Fabric reference workflow uses bronze (raw), silver (enriched) and gold (curated) lakehouse layers. This is architecture documentation, not a live integration claim. Source: https://learn.microsoft.com/en-us/fabric/onelake/onelake-medallion-lakehouse-architecture. Read October 26, 2026.

All incidents, subjects, districts and locations in the working dashboard are deterministic synthetic data. No source contains real criminal histories, convictions or population-based crime rates.
